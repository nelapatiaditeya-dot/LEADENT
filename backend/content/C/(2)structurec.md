Every C program follows a basic structure. This structure helps the computer understand where the program starts and what it should do.
A simple C program looks like this:
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}

Explanation:
#include <stdio.h> → Includes standard input/output functions
int main() → The starting point of the program
{ } → Contains the program code
printf() → Displays output on the screen
return 0; → Ends the program
