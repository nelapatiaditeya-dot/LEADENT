Variables
A variable is a container used to store data.
Example:
int age = 15;

Here, age is a variable storing the value 15.
Data Types
Data types define the type of data a variable can store.
Data Type
Meaning
Example
int
Integer numbers
10, -5
float
Decimal numbers
3.14
char
Single character
'A'

Example:
int marks = 90;
float pi = 3.14;
char grade = 'A';
